# ⚔️ LifeQuest: The Java Backend Journey

![LifeQuest Hero](imgs/an-open-book-with-a-sword-and-stars-on-it-vector.jpg)

**LifeQuest** is a personalized RPG gamification app designed to transform the journey of becoming a Java Backend Developer into an epic adventure. Stop tracking habits, start conquering worlds!

## 🎯 The Vision
As self-learners, we often lose motivation when studying complex backend technologies like Spring Boot, PostgreSQL, Docker, and Microservices. LifeQuest solves this by turning every module into a **World**, every project into a **Boss**, and every tutorial into a **Quest**.

By the time you defeat the "Final Boss" (The Backend Interview), you won't just have a high-level character in-game—you will be a job-ready Software Engineer in real life.

## 🚀 Features (MVP)
- **World & Boss System**: Progress through worlds (Java Fundamentals ➔ SQL ➔ Spring Boot ➔ DevOps).
- **Player Progression**: Earn XP, Gold, Level Up, and unlock Job Titles (Beginner ➔ Junior Backend).
- **Dynamic Quest System**: Daily coding quests with difficulty tags (Spring, Docker, Git).
- **Fatigue System**: Encourages healthy learning habits. Mentors remind you to rest to prevent burnout.
- **Legacy Monument**: A persistent record of life-changing milestones (e.g., "Deployed First REST API").

## 🛠️ Technology Stack
### Current Architecture (Phase 1)
- **Frontend**: React + Vite + TypeScript
- **Styling**: Vanilla CSS (Glassmorphism & Dark RPG Theme)
- **State Management**: React Context API
- **Data Persistence**: LocalStorage (Auto-save)

### The Master Plan (Phase 5 Evolution)
LifeQuest is designed to be self-hosting. In Phase 5, this project will evolve from a LocalStorage frontend app into a full-stack Spring Boot application—acting as its own Backend Portfolio piece!
- **Backend API**: Java Spring Boot
- **Database**: PostgreSQL
- **Security**: Spring Security + JWT
- **Deployment**: Docker + AWS/Heroku

## 🎮 How to Play (Run Locally)
1. Clone the repository.
2. Open terminal in the project directory.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the game engine (Dev Server):
   ```bash
   npm run dev
   ```
5. Open your browser at `http://localhost:5174` and begin your journey.

*(Tip: You can use the `LifeQuest.bat` file to launch the game directly as a Desktop App on Windows).*
